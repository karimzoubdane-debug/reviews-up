# Reviews UP

Application web de gestion IA des avis Google et des campagnes WhatsApp pour Voyages 21.

## Objectif

Reviews UP aide Voyages 21 a relancer ses vrais clients par WhatsApp pour les inviter a laisser un avis Google authentique, avec une suggestion redactionnelle modifiable, un rythme prudent de campagne, un historique complet et une validation humaine des reponses aux avis.

## Principes

- Le client reste libre de modifier, ignorer ou rediger son propre avis.
- Aucune demande de note specifique ou de 5 etoiles.
- Aucun avantage offert en echange d'un avis.
- Pas de publication au nom du client.
- Rythme progressif pour eviter les pics artificiels.
- Traçabilite des campagnes, messages et validations.

## MVP

La premiere version couvre :

- connexion securisee ;
- roles utilisateurs ;
- import Excel ;
- gestion clients, categories et langues ;
- creation de campagnes ;
- generation IA des messages ;
- validation avant envoi ;
- historique ;
- recommandation anti-rush ;
- tableau de bord simple.

## Phases suivantes

- Integration WhatsApp Business Platform officielle.
- Verification puis integration Google Business Profile.
- Suivi automatique des avis.
- Generation et validation des reponses.
- Notifications WhatsApp et rapport hebdomadaire.
